## 2. 逐门课程要点 / Course-by-Course Takeaways

**Introduction to Python**（2024-03）
Python 语法基础、变量与数据类型、函数与包、NumPy 数组运算。
*Python syntax, variables and data types, functions and packages, NumPy arrays.*

**Intermediate Python**（2024-03）
字典与 pandas 入门、Matplotlib 绘图、逻辑控制与循环、Hacker Statistics 案例。
*Dictionaries and pandas basics, Matplotlib plotting, control flow and loops, Hacker Statistics case study.*

**Data Manipulation with pandas**（2024-03）
DataFrame 的查看、索引与排序、筛选、分组聚合、切片、透视表与时间序列。
*Inspecting, indexing and sorting DataFrames, filtering, group-by aggregation, slicing, pivot tables and time series.*

**Cleaning Data in Python**（2024-04）
缺失值处理、数据类型转换、异常值识别、文本与数值清洗、去重与数据规整（tidy data）。
*Missing data, type conversion, outlier detection, text and numeric cleaning, deduplication and tidy data.*

**Exploratory Data Analysis in Python**（2024-04）
分布与汇总统计、变量间关系、相关性分析、多变量探索与"先看数据再建模"的思维。
*Distributions and summary statistics, relationships between variables, correlation analysis, multivariate exploration.*

**Supervised Learning with scikit-learn**（2024-04）
k-NN 与逻辑回归分类、线性 / Ridge / Lasso 回归、正则化、混淆矩阵与 ROC/AUC、交叉验证、网格搜索调参、Pipeline。
*k-NN and logistic regression, linear / Ridge / Lasso regression, regularization, confusion matrix and ROC/AUC, cross-validation, grid search, pipelines.*

**Unsupervised Learning in Python**（2024-05）
K-Means 与层次聚类、t-SNE 可视化、PCA 降维、NMF 特征提取与推荐系统。
*K-Means and hierarchical clustering, t-SNE visualization, PCA, NMF and recommendations.*
